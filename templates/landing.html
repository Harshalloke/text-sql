Safe by default.

A tool that talks to your database should be careful with it. Here is what QueryMind refuses, every time.

  • Drop, alter or truncate a table. The structure stays yours.
  • Run several statements in one go.
  • Change a row without telling you how many first.
  • Return an endless result. Every query gets a LIMIT.

Everything else, it will try.

Try all three. Sample data, nothing real is touched.

Questions.

Can it change my data?

Yes, but never silently. Inserts, updates and deletes show what will change and how many rows, then wait for your confirmation. Structural changes like dropping a table are blocked.

What if it writes the wrong SQL?

You can open the query behind any answer and read it. If a query fails, you get a plain-language explanation of what went wrong and what to try next.

What can I connect?

SQLite, MySQL and PostgreSQL databases, or a CSV or Excel file that gets loaded as a table you can ask about.
